# غريب هناك

فيلم مصري (30 دقيقة، ممكن 45) بالعامية المصرية، مصنوع بالذكاء الاصطناعي.

- **القصة**: شاب يترك أهله وأحبّائه ويسافر للعمل بعد ما فشل في إيجاد شغل بأجر كويس في مصر. الصراع، الفراق، الفشل، ثم الانتصار.
- **الأغنية**: "غريب هناك" (أم النوبي)، بتغنيها أم لابنها المغترب؛ مزروعة داخل الفيلم، والفيلم مش مبني على قصتها.
- **الكتابة**: بروح وحيد حامد. **الإخراج**: بروح علي بدرخان.
- **قاعدة**: ممثلين وحركة ومطابقة شفايف، بدون راوي على صور ثابتة.

## الخطوات التالية
1. معالجة وسيناريو (`skills/egyptian-screenplay`).
2. Character bible للبطل والأم والحبيبة.
3. اختبار مشهد واحد (دقيقتين) قبل الإنتاج الكامل.
